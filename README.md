# Cuota justa

Aplicación personal de una sola página que proyecta partidos de fútbol y estadísticas de jugadores (remates, remates al arco, entradas, atajadas) a partir de datos de StatsHub, calcula cuotas justas y las compara con las de las casas de apuestas.

- App: https://aramiskk.github.io/cuota-justa/
- Los datos que importes se guardan solo en tu navegador; nada se sube a este repositorio.
- Las probabilidades son estimaciones estadísticas, no garantías.
